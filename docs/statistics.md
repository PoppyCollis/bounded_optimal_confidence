# Statistics on the fits

Code: `src/bounded_optimal_confidence/stats/`. Scripts: `scripts/bayesian_model_selection.py`,
`scripts/paired_tests.py` and `scripts/plot_bms.py`, each with `--paper` for the paper's fits, `--smoke` for the
newest smoke runs, or neither for the newest full runs.

Everything starts from the per-subject AIC of each model's fit (`fit_results.csv`, read by `runs.load_fits`). Every
model has to cover the same subjects. The log model evidence of a subject is approximated by −AIC / 2.

## Random-effects Bayesian model selection (`stats/bms.py`)

Summed AIC says which model fits the group best in total. BMS (Stephan et al. 2009; Rigoux et al. 2014) instead
treats each subject's data as generated by one of the K models, drawn from unknown population frequencies r, and
asks which model is the most common. r has a Dirichlet prior with counts α₀. A variational scheme fits the posterior:
with L the K × N log-evidence matrix, iterate

    z_kn  ∝ exp(L_kn + ψ(α_k))          the probability that subject n's data come from model k
    α_k   = α₀_k + Σ_n z_kn             prior count plus the subjects attributed to model k

until the free energy F₁ (a lower bound on the log evidence of this model of the group) changes by less than 1e-8.
From the posterior Dirichlet(α):

| quantity | meaning | code |
|---|---|---|
| frequency | E[r_k] = α_k / Σα: the expected share of the population best described by model k | `BMSResult.frequency` |
| XP | p(r_k > r_j for all j ≠ k): the probability that model k is the most common one | `exceedance_probability` |
| BOR | Bayesian omnibus risk: the posterior probability of the null "all models equally common" | `omnibus_risk` |
| PXP | XP (1 − BOR) + BOR / K: XP protected against the null (Rigoux et al. 2014, eq. 7). The number to report | `BMSResult.pxp` |

XP is computed by numerical integration in the Gamma representation of the Dirichlet (Soch & Allefeld 2016).

**Priors.** `bms` uses the flat Dirichlet α₀ = 1 per model, as spm_BMS and both papers do. The `groupBMC`
package's default is 1 / K per model. **BOR** is computed from the exact log evidence of the null, Σ_n log Σ_k (1/K)
exp(L_kn), against F₁. groupBMC's own `F0` takes log α₀ as the null frequencies, which is only right under its default
prior; with α₀ = 1 it returns BOR = 1 and PXP = 1 / K for every model. Under the default prior the two agree
(`tests/test_bms.py`).

**Model-set dependence.** Similar models share subjects, so a model's PXP drops when a near-twin is added. The
10-model run answers "which of these ten is the most common"; the question "attention or not" is put separately.

**Family level** (`family_bms`; Penny et al. 2010). The models are grouped into families and the counts of a
family are the sums of its members' counts. The prior is 1 per family, split equally among its members, so a family
is not favoured for having more members; the null is every family equally common, split equally inside. groupBMC's
own family prior, 1 / (families × size) per model, sums to 1 instead of to the number of families; it is run as a
sensitivity check. `stats.tables.family_bms_tables` runs Diff against the Sym Top-2 family {hard, soft}, at the
model level and at the family level under both priors.

## Paired tests (`stats/paired.py`)

For a model against a reference (Diff), the difference d = AIC(model) − AIC(reference) is taken subject by subject,
so **positive means the reference fits better**; the summed d is the model's ΔAIC. `paired_test` gives

- the sum with its percentile-bootstrap 95% CI (`stats/bootstrap.py`: 10,000 resamples of the subjects, seed 0, so
  every model is resampled with the same subject indices). These are the error bars of the ΔAIC figure;
- the mean, the sd (n − 1), the two-tailed paired t-test (`scipy.stats.ttest_rel`) with the 95% CI of the mean and
  the effect size d_z = mean / sd;
- the exact two-tailed Wilcoxon signed-rank test (`scipy.stats.wilcoxon`), which does not assume normal differences;
- the number of subjects the model fits better (d < 0).

## Figures (`scripts/plot_bms.py`, `plotting/bms_figures.py`)

`figures/paper/bms_table.png` is the 10-model table above and `figures/paper/bms_pxp_bars.png` the PXP per model,
with the chance level 1 / K dashed. The bars use the layout of the paper's ΔAIC figure (`plotting/model_bars.py`):

short labels.

## Provenance

In `ITBR_confidence` the BMS lived in `paper_plots/fig_pooled_bms.py` (10 models, figures) and
`paper_plots/pooled_bms_family.py` (Diff vs Sym Top-2), the bootstrap in `paper_plots/bootstrap_ci.py`; the VB fit
and XP came from the `groupBMC` package (1.0, MIT), BOR and PXP from the scripts. Here the scheme is written out in
`stats/bms.py`, operation for operation as in groupBMC, and `tests/test_bms.py` checks it against the package (a dev
dependency). On the same input the new BMS and bootstrap equal the old scripts' to the last bit. The old scripts
read the AIC with pandas' default float parser, which is off by one ulp (about 2e−13) on 23 of the 130 stored values;
`runs.read_fit` recovers them exactly, so the printed numbers agree to better than 1e−12. The paired t-tests had no
script in the old repo; the two in its notes (hard and soft Sym Top-2 vs Diff, 2026-10-04 and 2026-10-08) are
reproduced with the sign flipped. The notes gave the hard Sym Top-2 Wilcoxon p as 0.147; the exact value is
1200 / 8192 = 0.1465.
